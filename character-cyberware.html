Starting sheet guide

Character creation

Use your chosen Cyberpunk RED creation method and enter the resulting stats and skills. This tool does not assign starting values or bypass Role rules.

Buying versus installing

Purchased cyberware stays in inventory. Installation requires a GM-confirmed procedure and an entered actual Humanity loss. Removing an implant does not automatically restore Humanity.

Roll modifiers

Only effects explicitly mapped to the selected roll are added. Unsupported implants are displayed as informational and never produce invented bonuses. Special rules and exploding d10s are handled by the roll engine.

NET actions

Netrunning Interface rolls use 1d10 + Interface rank + applicable NET modifiers, not a normal STAT + Skill roll. Programs require compatible cyberdeck slots and their actual program rules.

Visual cyberware manager

Select a body marker or category panel to inspect implants and eligible upgrades. Left/right markers identify anatomy; existing inventory records are not yet side-specific.

Owned inventory / NET cards

Cyberdeck and program reference

Cyberdecks, Attackers, Defenders, Boosters, Black ICE and hardware use their own rules and deck capacity. Program cards are inventory records until equipped and validated. No generic skill bonuses are assumed.

Market & upgrades

Automated rolls

The built-in roller resolves natural 10/1 critical rolls. Each roll now emits a cyberpunk-red:roll event and records a local roll payload for a future Fantastic Dice adapter. The animation is not yet connected.

Reference & audit

Modifiers are derived from installed items, not purchased items. Every contribution appears in the breakdown. Cyberware that changes a roll only in specific circumstances requires its condition to be satisfied.

Roll integration reference

All roll results must use the same derived modifier breakdown. A visual dice renderer may animate the final expression, but the rules engine must remain authoritative. The event cyberpunk-red:roll provides the dice result, modifier sources, DV and success; localStorage key cyberpunk-red-last-roll-v1 stores the last result for same-origin interfaces. For NET checks use Interface rank, not TECH/INT; for conditional bonuses explicitly mark the relevant circumstance. A loaded program does not automatically grant a general skill modifier.
