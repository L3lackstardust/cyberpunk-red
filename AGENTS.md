# Cyberpunk RED project continuity

At the start of work, read HANDOFF.md and docs/project-command-protocol.md.
Fetch the latest checkpoint when network access is available; inspect local changes before integrating upstream updates. Preserve uncommitted work.

Use HANDOFF.md as the concise shared checkpoint, not a claim of live desktop status. Reconcile it with newer commits and the user's latest explicit instructions. Recommendations are not automatically approved scope.

At meaningful milestones and before ending a development session, update HANDOFF.md with the branch/commit, actual changes, tests run and results, blockers, and next action. Re-read upstream before writing to avoid losing another session's update. Use task branches for concurrent code work; never force-overwrite checkpoints.

This repository is public. Store only project-relevant technical summaries, not raw chat histories, private campaign data, character saves, credentials, or personal details.

These instructions do not create a background process, direct desktop link, or automatic access to other conversations.
